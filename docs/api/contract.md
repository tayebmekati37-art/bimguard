# BIMGuard API contract

Version: 1.0.0 (Milestone 15)

Every endpoint below is part of the stable API. All endpoints except
`POST /auth/login` require a Bearer token in the `Authorization` header.

Roles: `admin`, `bim_coordinator`, `engineer`, `reviewer`, `viewer`.
Read endpoints are open to any authenticated user unless noted.

## Authentication

Send `Authorization: Bearer <token>` on every request except `POST /auth/login`.
The token comes from the `access_token` field of the login response.

## Errors

- `401` - missing or invalid token
- `403` - authenticated but not permitted
- `404` - resource not found
- `409` - conflict (duplicate, archived project, already acknowledged)
- `422` - validation error (body shape, field values)

## Stability

Everything in this list is stable. Additions are allowed; removals and
renames are not. If a breaking change is ever needed it gets a new path.

Generated by `scripts/generate_api_contract.py` from `app.main.app.routes`.
The purpose column is maintained by hand. Regenerate whenever endpoints
change; add a purpose for new ones.
